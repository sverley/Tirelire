# Les domaines

Un domaine est un bloc fonctionnel du produit (D86). Chaque tâche du produit porte l'étiquette de
son ou de ses domaines ; le travail, lui, est tiré et ordonné par les versions (`docs/versions.md`,
D87).

Un document de domaine dit son intention, avec les paroles du porteur qui la fondent, citées mot
pour mot, et son analyse — contraintes, hypothèses, cibles, usages — quand une issue de conception
l'a faite. Il ne liste ni tâches, ni ordre, ni état : ils restent sur GitHub.

- `budget-et-tirelires.md`
- `plan-et-flux.md`
- `operations.md`
- `rapprochement-et-bilan.md`
- `donnees-et-synchro.md`
- `assistant-et-exemple.md`
- `application.md`
